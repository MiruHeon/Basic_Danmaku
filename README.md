# Basic_Danmaku
탄막 게임 만들기

## 1일차
'컴퓨터 그래픽스'의 정점 => 게임<br>
좋은 게임을 만들긴 위해선, 스토리와 음악, 그래픽 등의 요소가 빠짐없이 있어야 한다.

사실상 대부분의 게임이 '배열'에서 시작이 된다고 할 수 있다.
x좌표와 y좌표를 배열로 만들면, 2차원 배열이 되고, app[x][y] 형태로 생각보다 다양한 그래픽 작업을 수행할 수 있다.

1080*1920의 픽셀을 가진 모니터의 관점으로 보자면, RGB의 값을 moniter[1080][1920] 이런식으로 조작할 수 있다는 말이다.

## 2일차
세밀한 픽셀 조작 능력이 그래픽으로 이어진다.<br>
배열으로 화면을 구성하는 것도 중요하지만, 그에 맞는 알고리즘, 키보드 인터럽트, 타이머, FPS 조절 또한 아주 중요한 요소이다.
예를 들자면, 테트리스에서는 한 행의 요소들이 꽉 찼을 때, 한 행을 비우는 알고리즘이 필요하다는 소리이다.
